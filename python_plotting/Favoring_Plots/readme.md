This code compares neutral, Bell-priority, and GHZ-priority switch resource-allocation policies for selected values of kSW = kBell + kGHZ. For each requested kSW value, it matches the corresponding allocations in the policy and neutral CSV files, normalizes the total rate using the neutral Bell-only rate, and generates a separate two-panel figure showing the normalized total rate and the Bell share of the total rate; each figure is saved in both PNG and PDF formats in the plots folder. Place switch_policy_plots.py in the same directory as run_switch_resource_allocation_sweep_joint_transmission.csv and switch_resource_allocation_sweep(1).csv, then run `python switch_policy_plots.py` and enter the desired kSW values when prompted (for example, `10,20,50` or `all`), or provide them directly with `python switch_policy_plots.py --ksw 10,20,50`.
